# zxc

自行车 is a simple CLI agent intended for local models. It's meant to help you get where you're going faster, but you still have to pedal.

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run start
```

To show responses in MarkDown with the `/md` command, you'll need [Glow](github.com/charmbracelet/glow) installed.
